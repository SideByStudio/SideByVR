# Third-party dependencies and resources

The application code is licensed under Apache-2.0. This does not replace the licenses of its dependencies or their transitive dependencies.

The current direct runtime dependencies are Flutter, cupertino_icons, path_provider, image, shared_preferences, archive and video_player. Their resolved versions are recorded in `pubspec.lock`. Flutter's generated license registry includes notices supplied by Dart packages; Android native dependencies must also be reviewed before distribution.

The initial migration has not completed a full third-party source, native dependency, font, codec or resource license audit. This document is an inventory starting point, not a certification that all distribution obligations have been completed. Applicable notices will be collected before the first public release.

No external demonstration media is bundled. The launcher vector is newly created for this repository; the menu uses Flutter Material icons. The prior commercial raster branding and screenshots are not included. The Gradle wrapper files are provided by Gradle and retain the notices in those files; Gradle is distributed under Apache-2.0.
