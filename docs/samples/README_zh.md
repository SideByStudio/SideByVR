## 📥 下载与查看

1. 打开样例，通过浏览器下载或保存原始 `.sbs.jpg`。
2. 保留 `.sbs.jpg` 后缀，将文件放入 Android 本地文件夹。
3. 在应用选择 **Select local folder**（选择本地目录），授权后打开 **SBS media in this folder**（本目录的 SBS 媒体）。
4. 若浏览器把文件名改为普通 `.jpg`，开启 **Include ordinary images as SBS**（普通图片 SBS 模式），也可按 R / RB。

缩略图只有单眼画面，不能作为 SBS 文件使用。这些 URL 是浏览器下载入口；开源查看器读取下载后的本地文件，不会自动连接在线媒体库。操作细节见[使用说明](../usage_zh.md)。

目录快照：2026-10-16，共 18 张图片。来源：[公开目录接口](https://sideby.cc.cd/api/samples/v2)。内容和可用性可能变化，以网站最新目录为准。外链媒体适用网站的相关条款，不因代码仓库使用 Apache-2.0 就自动改用该许可证。
