# 🖼️ Online SBS samples

English | [简体中文](README_zh.md)

Browse the [sample library](https://sideby.cc.cd/samples/). The previews load single-eye thumbnails from the public asset domain. **Click a preview or Download SBS to open the full side-by-side image.** This repository stores links only, not sample image files.

## 📥 Download and view

1. Open a sample and save the original `.sbs.jpg` using your browser's download/save-image action.
2. Keep the `.sbs.jpg` filename and place it in a local Android folder.
3. Choose **Select local folder**, grant access and open **SBS media in this folder**.
4. If your browser changes the name to an ordinary `.jpg`, enable **Include ordinary images as SBS** (R / RB).

Thumbnails contain only one eye and cannot serve as SBS files. These links are browser downloads; the open-source viewer reads the downloaded local files and does not automatically connect to an online library. See the [usage guide](../usage.md).
