# Feedback

English | [简体中文](feedback_zh.md)

This repository is being prepared locally. Once it is published on GitHub with Issues enabled, use **Issues → New issue**. There is no live public feedback URL yet.

## Choose a report

- [Bug report](../.github/ISSUE_TEMPLATE/bug_report.md): crashes, errors or behavior that differs from the documentation.
- [Device compatibility](../.github/ISSUE_TEMPLATE/device_compatibility.md): successful or failed device, controller, storage or codec checks.
- [Feature request](../.github/ISSUE_TEMPLATE/feature_request.md): the viewing task and missing capability.

Check [supported formats and controls](usage.md) first. Ordinary image names require the Images as SBS switch; ordinary MP4 files are not selected. Enabling the switch does not convert 2D photographs to stereo.

Include the app version/commit, phone model, Android version, reproduction steps and expected/actual results. For media issues include dimensions, extension, layout and video codec if known. For controller issues include its model and USB/Bluetooth connection. Successful reports should list checks actually performed.

Use a simple sample you may share, or the [online samples](samples/README.md). Remove private images, filenames, paths and credentials from logs/screenshots. Do not post exploitable security details or sensitive data in public issues; a private security-reporting channel remains to be configured before publication.

Response times are not guaranteed. Reproducible viewer and compatibility issues are the initial focus; hosted conversion, accounts and billing are outside this repository's scope.
