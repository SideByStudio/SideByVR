# Viewer roadmap

English | [简体中文](roadmap_zh.md)

## Before the first public preview

- Complete clean-checkout build verification and physical-device regression: SAF authorization/restart, offline images and ZIPs, controller cold-start focus and video playback/exit.
- Confirm the publication repository, issue intake and a private security-reporting channel.
- Decide the release artifact and signing approach; recheck the final artifact's notices and signature.

## After initial feedback

- Evaluate Half-SBS aspect correction and left/right eye selection with representative samples.
- Improve viewing controls and compatibility based on reproducible device reports.
- Assess top/bottom layouts and dedicated stereo formats such as JPS/PNS/MPO separately, including parsing and eye order.
- Evaluate optional LAN browsing only after the standalone local viewer is reliable.

These are priorities rather than delivery dates. The first scope is viewing existing SBS media; publishing a generation pipeline or hosted account/billing services is not a milestone of this viewer roadmap.
