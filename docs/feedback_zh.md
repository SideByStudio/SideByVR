# 反馈说明

[English](feedback.md) | 简体中文

仓库目前处于本地筹备阶段。发布到 GitHub 并启用 Issues 后，可通过 **Issues → New issue** 提交；当前尚无公开反馈地址。

## 选择反馈类型

- [问题报告](../.github/ISSUE_TEMPLATE/bug_report_zh.md)：崩溃、错误或与说明不符的行为。
- [设备兼容性](../.github/ISSUE_TEMPLATE/device_compatibility_zh.md)：设备、手柄、存储或视频编码的成功及失败结果。
- [功能建议](../.github/ISSUE_TEMPLATE/feature_request_zh.md)：希望完成的查看任务与缺少的能力。

先查看[格式支持与操作说明](usage_zh.md)。普通图片名需要主动开启 SBS 开关，普通 MP4 不会显示；开关不会将二维照片转换成立体图。

请注明应用版本或提交、手机型号、Android 版本、复现步骤以及预期和实际结果。媒体问题补充分辨率、后缀、立体布局和已知视频编码；手柄问题补充型号和 USB/蓝牙连接方式。成功报告也请列出实际检查项目。

优先使用可公开分发的简单样例或[在线样例](samples/README_zh.md)。日志和截图中请删除私人图片、文件名、路径和凭据。不要在公开 Issue 中发布可利用的安全细节或敏感数据；私密安全报告渠道仍待公开前配置。

不保证固定回复时间。初期优先处理可复现的查看与兼容性问题，云端转换、账号和支付不属于本仓库范围。
