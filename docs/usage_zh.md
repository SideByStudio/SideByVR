| 物品 | 准备说明 |
| --- | --- |
| 安卓手机 | 安装 SideByVR Viewer，将 SBS 文件下载到本地文件夹。 |

## 开始使用

通过 Android 系统文件夹选择器授权目录。应用保存目录授权和上次浏览位置；授权有效时可使用 **Continue last folder**（继续上次目录）。Android 可能限制对部分系统目录的访问。

浏览器展示子目录、ZIP 和当前目录的媒体组。默认接受 `.sbs.jpg`、`.sbs.jpeg`、`.sbs.png`、`.sbs.mp4`，不区分大小写。普通 JPG/JPEG/PNG 文件名需要主动开启 **Include ordinary images as SBS**（将普通图片作为 SBS 查看），可点击按钮或按键盘 R / 手柄 RB。

该开关作用于当前浏览会话的子目录、ZIP 和跨图集浏览；退出浏览页后重置，关闭后恢复仅带标记文件的过滤规则。普通照片不会因此转换成立体图，图片内容本身必须已有左右眼画面。

## 操作方式

- 菜单：方向键或左摇杆选择，A、Y 或 Enter 打开，LB 切换手机/VR 菜单，B 或 Escape 返回或退出。
- 文件夹浏览：X 或 Backspace 返回上级，RB 或 R 切换普通图片 SBS 模式。
- 图片查看：左摇杆上下缩放，左右切图；键盘左右键也可切图。右摇杆移动画面，A/X 调眼间距，Y 重置，RB 切换提示层，B 或 Escape 返回。
- 视频查看：方向键左右快退/快进 5 秒，上下调音量，Y 播放/暂停；摇杆、A/X 和 RB 保留查看器中的作用。
- 键盘支持不完整：左右键和 Escape 可用，缩放、位移、眼间距及提示层需要手柄或对应设置。I/K/J/L 和键盘上下键不控制静态图片的移动或缩放。
- 支持连续摇杆输入，实际手柄映射仍待真机回归。

菜单支持触摸，查看操作建议使用手柄。当前为平面 SBS 显示，不提供头部追踪、镜片畸变校正或 180/360 球面投影。

## 本地数据

应用读取用户明确授权的目录，并把打开的媒体复制到私有缓存；偏好设置保存目录位置和查看参数。不包含账号或云端上传流程。Android Debug/Profile 构建保留 Flutter 开发网络权限，主应用清单不请求互联网权限。

发布前仍需真机验证视频编码、大 ZIP、手机与手柄组合。

## 格式支持与验证

| 输入 | 浏览行为 | 验证与限制 |
| --- | --- | --- |
| `.sbs.jpg`、`.sbs.jpeg`、`.sbs.png` | 默认显示，不区分大小写 | 已自动验证合成 JPEG/PNG 解码与左右眼颜色拆分 |
| 普通 `.jpg`、`.jpeg`、`.png` | 主动开启普通图片模式后显示 | 已验证目录开关、实际解码、返回及关闭模式 |
| `.sbs.mp4` | 默认显示，不区分大小写 | 保留播放链路，真机与编码兼容性待验 |
| 普通 `.mp4` | 不显示 | 已有 SBS 视频可改为 `.sbs.mp4`；重命名不转换内容 |
| ZIP | 同样的过滤规则，支持嵌套条目 | 已验证提取、模式缓存失效及路径穿越拒绝 |
| GIF、WebP、JPS/PNS、MPO、上下排列 | 浏览入口不支持 | 后续评估，不能靠重命名推断支持 |

左右半图分别送往对应眼睛，并保留半图比例，即 Full-SBS 假设。Half-SBS 横向校正和眼序交换暂缓。建议使用偶数宽图片，奇数宽末尾一列当前会被舍弃。PNG 拆分后内部编码为 JPEG，不保留透明通道和无损特性；没有自动立体布局检测。

自动化检查使用生成的彩色图片和模拟 Android 存储调用，不能替代真机 SAF 提供方、显示效果、手柄和视频验证。ZIP 最多选择 2000 个媒体条目，声明的未压缩选中内容最多 2 GiB；低于限制不代表所有设备都能正常打开。

## 将自己的 2D 图片转为 SBS

1. 在浏览器打开 [SideByVR 在线转换](https://sideby.cc.cd/zh/create/)，使用 Google 账号登录；新账号获赠 10 Credits。
2. 上传你拥有处理权利的 JPG。成功生成一张图片扣除 1 Credit；处理失败会释放预留积分。
3. 在网站私人媒体库下载完整 SBS 原图到手机。原图最多保留 24 小时，生成结果最多保留 30 天，请及时下载。
4. 在 Viewer 授权下载目录。使用 `.sbs.jpg` 文件名，或开启普通图片 SBS 显示；该开关只影响文件选择，不会生成立体内容。

在线转换是可选的独立服务，适用网站的[定价](https://sideby.cc.cd/zh/pricing/)、[服务条款](https://sideby.cc.cd/zh/terms/)与[隐私政策](https://sideby.cc.cd/zh/privacy/)。本地查看无需账号或 Credit。
