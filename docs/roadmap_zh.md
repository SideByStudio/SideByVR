# 查看器路线图

[English](roadmap.md) | 简体中文

## 首次公开预览前

- 完成干净检出构建及真机回归：SAF 授权与重启恢复、离线图片和 ZIP、手柄冷启动焦点、视频播放与退出。
- 确定公开仓库、问题反馈入口和私密安全报告渠道。
- 确定发布产物与签名方式，重新核验最终产物的声明和签名。

## 收到首批反馈后

- 使用代表性样例评估 Half-SBS 比例校正和左右眼选择。
- 根据可复现的设备报告改善查看操作和兼容性。
- 分别评估上下排列及 JPS/PNS/MPO 等格式，包括解析与眼序。
- 在独立本地查看器稳定后评估可选的局域网浏览。

以上是优先级，不是交付日期。首版聚焦已有 SBS 媒体查看，公开生成流水线或托管账号/支付服务不属于本路线图的里程碑。
