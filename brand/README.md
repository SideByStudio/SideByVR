# SideByVR icon

English | [简体中文](README_zh.md)

The project author created `sideby-vr-icon-master.svg` and licenses it, together with the application code and derived launcher resources, under [Apache-2.0](../LICENSE).

Android launcher resources in `android/app/src/main/res/` reuse the existing exports of this master: density-specific PNGs for legacy launchers and a simplified vector foreground with a solid background for adaptive launchers. The adaptive version intentionally omits the SVG glow and background rings.

`sideby-vr-icon.png` is a 512-pixel export of the official SVG for the home and About screens, under the same Apache-2.0 license.
